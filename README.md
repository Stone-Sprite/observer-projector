# Observer Projector 观察者投影机 0.1.2

Minecraft 1.21.11。两个 loader 各一份，装到对应实例的 mods 目录即可。

## 安装

| 文件 | 放哪儿 |
|---|---|
| observerprojector-0.1.2-neoforge.jar | NeoForge 21.11.42 实例的 mods/ |
| observerprojector-0.1.2-fabric.jar   | Fabric Loader 0.19+ 实例的 mods/ |

## 用之前必须先有 ffmpeg

按顺序找这几个位置，任意一个存在即可：

    D:\hiyori\resources\tools\ffmpeg.exe
    D:\dsh-build\tools\ffmpeg.exe
    C:\ffmpeg\bin\ffmpeg.exe

都不在就回退到 PATH 里的 ffmpeg。视频和音频都靠它解码，没有它什么都放不了。

## 怎么用

1. 放一个侦测器在栅栏上，背面（红点那一侧）贴一个按钮
2. 右键侦测器 —— 它面向的那一边就是镜头方向
3. 正前方 5~15 格内要有不透光的墙，画面就投在墙上
4. 按 F6 可以开关整个投影

界面分三页：

- **播放页** —— 本地文件 / B站搜索 / CCTV 频道 / 粘任意地址。列表上方切换服务商。
  本地和 CCTV 单击即播（遥控式），B站单击选中、双击播放（解析要一两秒）
- **颜色页** —— R/G/B 增益、音量、色差强度，四根滑块，上方是实时色卡预览
- **高级页** —— 分辨率、帧率、投射角、自发光、遮挡β、翻转等开关

## 两个需要注意的开关

**自发光** —— 打开后用 beaconBeam 渲染类型，不采样世界光照贴图。
关掉用 entityCutoutNoCull：能显示，但黄昏时整幅会偏暖，看起来像蒙了层红遮罩。
这是光照贴图本身带时刻色调导致的，不是画面内容的问题。

**遮挡β** —— 仍是 beta。格与格之间可能有缝，投影仪离墙太近或角度太斜时更明显。
高分辨率加遮挡同时开会明显吃帧。

## 音符盒当音响

在投影仪周围 9x7x9 的范围里放一个音符盒，声音就从它那儿出来（而不是投影仪本身），
可以当外接音箱用。找不到音符盒时退回投影仪位置。
